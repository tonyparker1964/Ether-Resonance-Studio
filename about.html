ABOUT THIS PROJECT

One journal.
Three independent practices.

Ether Resonance Studio is a browser-based session journal for recording Spooky2 + Scalar, Muse, and FlameInSound sessions in one place while keeping each system's records distinct.

Open Ether Resonance Studio ↗View GitHub repository ↗
〰

Spooky2 + Scalar

Log GeneratorX model, output mode, program, Scalar setup, run time, and session notes.

◉

Muse

Record headset, practice type, app, duration, and an optional self-reported rating.

♨

FlameInSound

Capture the mobile device, session name, frequency shown, listening setup, and notes.

Privacy and saved records

Session entries are stored in your browser's local storage on the device you are using. Export CSV for a spreadsheet or JSON for a backup before clearing browser data or moving to another device.

Current integration status

This build records sessions; it does not connect to or control the instruments. Muse EEG is not read live, FlameInSound is not controlled from this page, and the three systems are not synchronized. The shared journal aligns entries by their recorded times only.
